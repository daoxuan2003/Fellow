# Architecture Decision Records

Use ADRs for decisions that future AI agents might otherwise repeatedly
reinterpret or reverse.

Create `ADR-NNNN-short-title.md` with:

```markdown
# ADR-NNNN: Title

- Status: proposed | accepted | superseded | deprecated
- Date: YYYY-MM-DD
- Owners: product owner / technical agent

## Context

## Decision

## Alternatives considered

## Consequences

## Verification and review trigger

## Related files / Issues / PRs
```

An ADR records why a decision exists. Executable behavior remains verified by
source and tests. Supersede an ADR explicitly rather than silently editing its
historical rationale.
