# 我们俩 - 情侣专属空间

> 一个只有你们两个人的私密小世界 💕

## 这是什么？

**我们俩** 是专为情侣设计的私密应用。绑定后，你们可以：

- 📦 **取件清单** - 互相帮忙记快递，再也不忘取
- 💑 **相爱天数** - 记录在一起的美好时光
- 🔔 **实时同步** - TA 的操作，你立刻知道

## 核心功能

### 📦 取件清单
- 添加快递，对方实时收到通知
- 紧急快递置顶提醒
- 标记已取，1天内可撤销
- 按月份整理已取快递

### 💑 情侣绑定
- 输入配对码，一秒绑定
- 绑定后共享纪念日
- 显示相爱天数

### 🎨 贴心设计
- 男生蓝色 / 女生粉色，一眼区分
- 手机端可添加到桌面，像原生 App
- 操作简单，长辈也能轻松用

## 快速开始

1. **注册** - 输入昵称、账号、密码
2. **绑定** - 输入对方的配对码
3. **使用** - 开始记录你们的甜蜜日常
